# Contributing to Jibo Auto-Mod

Jibo Auto-Mod belongs to the Jibo Revival community. Keep contributions focused
on the community's device access, recovery and conversion tools, their supported
formats, generic examples and reproducible validation.

Private robot inventories, purchase or delivery updates, personal experiment
logs, and another project's hosting, billing, subscription or commercial launch
plans belong outside this repository. Release notes should describe this tool's
changes and validation, without importing private project status.

Conversion targets remain explicit and provider-neutral. Document the supported
input contract here; users should consult their chosen server's documentation
for server-specific setup. Do not make a particular commercial service a default
or prerequisite for the community tool.

Before publishing, review both repository documentation and the extracted
release archive. The portable packager checks bundled documentation for known
cross-project references and private test notes. Existing `openjibo.*` schema
identifiers and the capture protocol are compatibility identifiers for retained
files; they are not product branding or a service enrollment requirement. Do
not rename those formats as part of a documentation change.
