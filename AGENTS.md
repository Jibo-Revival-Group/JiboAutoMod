# Repository scope

This is the Jibo Revival community's Auto-Mod repository. Follow
[CONTRIBUTING.md](CONTRIBUTING.md) for documentation and release scope.

Keep private robot experiments, purchase/delivery status, and separate platform,
hosting, subscription, billing or commercial launch plans outside this repository
and its release notes/archives. Use generic, provider-neutral examples and Jibo
Revival branding. Existing schema/protocol identifiers are compatibility contracts;
do not rename them as an editorial cleanup.

When changing documentation or packaging, run `test_community_scope.py` and the
portable release check, and inspect the extracted package before publication.
